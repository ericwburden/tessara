# Sprint 6B1 Executive Implementation Briefing

This is the executive-level Reveal.js presentation for the approved Sprint 6B1 implementation plan.

## Run locally

```powershell
npm install
npm start
```

Open `http://localhost:8000`. Use the arrow keys to navigate, `S` for speaker view, `O` for overview, and `F` for full screen.

The presentation is source-controlled HTML/CSS. Its implementation scope is grounded in `docs/roadmap.md` and the approved records in `docs/mockups/sprint-6b1/README.md`.
