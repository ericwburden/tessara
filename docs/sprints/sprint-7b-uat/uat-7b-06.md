# UAT-7B-06 — Archive and tombstone

Verify the versions table separates Publication from Lifecycle and uses the
shared vertical-dot action menu. Archive an eligible version only after the
irreversible confirmation, then verify reactivation is rejected and authorized
resolution exposes archived metadata without renderability. Tombstone the
archived fixture after its stronger confirmation; verify payload immutability,
typed tombstone resolution without metadata, no remaining actions, and an audit
trail. Compare restricted known and random projections for nondisclosure.
